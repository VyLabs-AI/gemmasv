Teach a language model to forget

Interactive demonstration of exact deletion from persistent in-context memory · Gemma-3-4B with an SV long-range memory graft

checking compute…

This is a mechanism demo, not a chatbot benchmark: a fictional conversation is placed in long-term context memory, one indexed field or complete record is recalled and deleted, and the resulting memory is compared with a retained-key refit without exactly those owned token positions. Use synthetic information only — never a real password, key, or patient record. Sessions are ephemeral and can be purged at any time.

Before you try it

Think of the model’s memory as a filing cabinet

A long conversation has already been filed away. Later, someone says: remove this diagnosis field, revoke this incident attribute, or delete every field in this record. Hiding the answer is not enough—we want to know whether the selected memory entries were actually removed.

1

Store a conversation

The old turns sit beyond Gemma’s local window, inside the grafted long-range memory.

2

Prove it remembers

Ask registered questions. The demo proceeds only if the model can retrieve every selected field.

3

Delete the selected field or record

The selected memory entries are decremented. The source conversation and Gemma’s weights are not silently rewritten.

4

Compare with “never stored”

We independently refit the retained memory keys without the selected positions and compare the two output distributions.

Behavioral evidence

Does recall fall to its never-stored floor, even when an adversarial prompt tries to recover it?

Certificate

At each registered question, how close is deletion to refitting without the selected scope? The full-vocabulary KL is shown.

What this does—and does not—prove
  • It certifies the grafted long-range memory at one registered audit question.
  • Other prompts are empirical attacks, not part of that certificate.
  • Purging an entire patient and all ingestion-time imprint requires the slower full-repack path.
  • It does not erase pretrained weights, external logs, backups, or copies supplied later.

What “exact” means here

  • The object: one indexed field or complete owned record in the grafted long-range context memory. Gemma’s pretrained weights are not being edited.
  • The check: incremental deletion versus refitting the same retained memory keys without that exact scope, reported as a float64 output KL at the registered question.
  • The boundary: other prompts are empirical stress tests. A fully repacked context, cached-neighbor imprint, saved pre-deletion outputs, external backups, and attacker-supplied copies are not covered by that certificate.

Questions are sent to the base model as completion probes (Question: … Answer:); answers are scored teacher-forced on the marked span against a repacked never-told floor.
